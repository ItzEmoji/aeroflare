Nix binary cache

https://this-host/ provides prebuilt binaries for Nix. Once it is added as a substituter, Nix downloads from it automatically instead of building locally.

API

  • /nix-cache-infoCache metadata
  • /api/public-keyPublic key the store paths are signed with
  • /<hash>.narinfoInformation about one store path
  • /nar/<file>The compressed store path

Using this cache

Add this URL as a substituter and trust the key from /api/public-key. The NixOS Wiki shows how to do that on NixOS and other systems: Binary Cache → Using a binary cache.

To run a cache like this one yourself, see the aeroflare documentation.
