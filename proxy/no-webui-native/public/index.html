Nix binary cache

This is a binary cache for Nix. It serves pre-built store paths to Nix clients and is not meant to be browsed.

To use it, add it to your nix.conf together with its signing key from /api/public-key:

extra-substituters = https://this-host
extra-trusted-public-keys = <key from /api/public-key>

Cache metadata: /nix-cache-info

Served by aeroflare.
