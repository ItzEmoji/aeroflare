Nix binary cache

Prebuilt binaries for Nix. Once this cache is added as a substituter, Nix downloads from it automatically instead of building locally.

https://this-host/

API

  • GET/nix-cache-infoCache metadata
  • GET/api/public-keyPublic signing key
  • GET/<hash>.narinfoInformation about one store path
  • GET/nar/<file>The compressed store path

Using this cache

NixOS Wiki → How to add a binary cache on NixOS and other systems. aeroflare docs → Run a cache like this one on your own registry.

Trust the key from /api/public-key together with the URL above, or Nix will reject the downloads.
